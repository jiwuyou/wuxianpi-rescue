# 安装收尾

`wuxianpi.setup-finish` 是首次安装完成后的独立收尾流程，不重新安装资源、不重启服务，也不改变已经完成的安装结果。

它读取现有 setup status 和 APK offer receipt，将已验证的版本、激活、连接和 Ubuntu 状态整理为一条简短的维修记忆。不会保存 Token、API Key、管理密钥、完整日志或整段对话。

如果发现失败或警告，先询问用户是否允许整理反馈。反馈草稿必须完整展示，用户可以先修改；只有用户确认后才保存草稿并显示最终发布确认卡片。反馈失败不能影响安装状态。

收尾最后显示：

> 首次安装已完成。
>
> 以后请直接使用 WuxianPi 完成日常对话、安装更新和问题处理。
> 维修助手主要用于首次安装和故障修复，和apk更新。

用户点击“打开 WuxianPi”后才进入桌面上的 WuxianPi。右上角“桌面”始终可以立即退出收尾流程。
