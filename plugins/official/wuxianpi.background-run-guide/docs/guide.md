# 后台运行指导

这个插件只提供查询和操作提示，不申请 Android 权限，也不会自动修改手机系统设置。所有需要复制的搜索词和提问话术都使用 Markdown 代码块展示。代码块右上角的方块符号就是复制按钮，点击它可以一次性复制代码块中的全部内容。

## 浏览器搜索

可以使用 Google 或百度搜索下面这句话：

```text
荣耀手机怎么打开应用的后台运行权限
```

## 向 AI 提问

可以把下面的问题发送给豆包、DeepSeek 或 ChatGPT：

```text
我正在安装 OpenHouse，需要让相关应用能够长期在后台运行。

我是荣耀手机用户，请说明如何为下面的应用开启后台运行、电池不受限制、自启动，或关闭系统自动管理：

OpenHouse All-in-One

请给出尽量具体的设置路径，并说明需要打开哪些选项。
```

如果使用 Native 版本，将应用部分替换为：

```text
Termux
OpenHouse Native
```

只处理与你当前安装包对应的应用。不同手机的设置名称可能不同，请以手机实际显示的设置页面为准。完成后返回 OpenHouse 并确认继续首次安装。
