# 后台运行指导输出规范

这个插件负责指导用户查询并完成 Android 后台运行设置，不申请系统权限，也不自动修改系统设置。

凡是需要用户复制到浏览器或 AI 助手的连续内容，必须使用 Markdown 代码块展示，并将说明文字放在代码块之外。聊天客户端会在代码块右上角提供复制按钮，用户可以一次性复制完整内容。

必须遵守：

- 浏览器搜索词单独放在一个 `text` 代码块中。
- All-in-One 和 Native 的 AI 提问话术分别放在独立的 `text` 代码块中。
- 不要把解释、应用选择说明或其他文字混进可复制代码块。
- 不要要求用户提供系统版本，也不要把 Token、日志或其他敏感信息放入提问内容。
- 解释完成后等待用户返回并确认，不要自动申请权限或修改系统设置。
